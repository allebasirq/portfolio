# Isabella's Portfolio

Personal portfolio website showcasing my projects, experience, skills, honors, and academic work.

Built with **React** and **Vite**.

## Technologies

* React
* JavaScript
* HTML
* CSS
* Vite

## Features

* Interactive project showcase
* Project images and technology lists
* Experience timeline
* Honors & awards
* Contact section
* Interactive binary rain background
* Responsive design

## Running Locally

Clone the repository:

```bash
git clone git@github.com:allebasirq/portfolio.git
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The website will then be available at `http://localhost:5173`.
